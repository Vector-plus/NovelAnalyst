# 长篇小说解说Agent

## 核心功能

1. 索引生成

解说目标是长篇小说（600万字左右），需要先建立索引目录。后续会根据索引目录进行检索和小说解析推理。索引目录设计文档：`novel-index-templates.md`

2. 解说词生成

用户输入目标任务，agent根据索引目录选择加载的文本内容，然后对内容进行归纳总结生成标准的解说词。

3. 系统运维

系统需要尽可能地满足生产要求，具备可观测能力。并且能实现Eval评测。

## 功能详细设计

### 索引生成

1. 上传文件

输入：小说文本（.txt文件）

响应：为小说文本生成沙箱环境（不同小说通过沙箱环境隔离），解析小说文本，保存小说原文到沙箱环境中。

2. 解析小说

输入：小说名称 + 解析LLM名称
响应：
    触发小说索引创建流程
    a. 在沙箱中为本次创建的索引目录生成一个带版本信息的路径，存放后续生成的索引文件
    b. leadagent分析任务，调`索引生成`sub_agent执行任务
    c. sub_agnet加载索引生成器的skills完成索引创建。主要包括：分块->逐块加载->分析文本->生成索引->可能涉及索引文件的新建、更新、追加操作

注意：索引生成任务是长任务，需要考虑断点恢复问题、任务完成进度和质量的check问题、以及check后索引目录优化问题


### 解说词生成
输入：解说词任务 + 小说名&索引目录版本
响应：
    触发解说词生成流程
    a. leadagent分析任务,调`解说词生成`sub_agent执行任务
    b. sub_agent加载解析skills完成解说词生成。主要包括：根据任务按需加载对应的skills -> 根据skills按需加载索引文件 -> 判断加载的文件是否完整，是否能支撑解说任务，如果不能支撑需要继续下钻加载更多内容 -> check解说词质量 -> 如果质量太低可以重新生成 如果无法完成任务需要反馈给用户 或者提醒用户进行修改


### 系统运维


## 系统核心功能设计

支持模型选择、skills管理、沙箱隔离、tools管理、多agent执行、状态管理（任务断点执行）、日志（用户请求、工具执行、LLM调用、错误日志）、异常捕获机制、评测优化
