# 五类解说稿 · 结构模板与字数控制

本参考文件给出五类解说的**稳定结构模板**、**字数区间**与**节奏/金句控制规则**，是 LLM 在撰稿阶段必须遵循的"排版骨架"。

字数口径：**稿件正文**（含标点、不含证据脚注、不含元信息块）。

---

## 一、章节剧情解说 · 结构模板

- 对应 task_type：`chapter_explanation`
- 字数区间：**1500 – 2500 字**（目标锚点 ~ 2000 字）

| 段落 | 字数区间 | 作用 |
|---|---|---|
| **① 开场钩子** | 100 – 200 字 | 冲突/悬念/反差切入；前 100 字必须有强钩子 |
| **② 前情回扣** | 150 – 300 字 | 极简串联此前关键伏笔（1–3 条即可）；不要复述上几章全部内容 |
| **③ 主体叙述** | 1000 – 1500 字 | 按原文顺序讲清**关键行动 → 转折 → 结果**；分 2–4 个小节、每节一画面 |
| **④ 解说点评** | 150 – 300 字 | 解说员视角的意味解读；对本章在剧情全局中的位置做轻度升维 |
| **⑤ 追更钩子** | 100 – 200 字 | 下一章悬念预告，必须对应 `thread-*.status=open` 的真实伏笔 |

**结构校验口诀**：钩 → 回 → 叙 → 评 → 勾。

---

## 二、人物传记解说 · 结构模板

- 对应 task_type：`biography`
- 字数区间：**1000 – 1500 字**（目标锚点 ~ 1200 字）

| 段落 | 字数区间 | 作用 |
|---|---|---|
| **① 命运开篇** | 100 – 200 字 | 代表性场景或关键选择切入；不写简历 |
| **② 起点** | 150 – 250 字 | 他的初始状态、他身上**不曾被夺走的那一样东西** |
| **③ 关键选择与代价** | 300 – 450 字 | 2–3 个关键选择；每个选择都要**配上代价**；用具体后果替代抽象描述 |
| **④ 变化与蜕变** | 250 – 400 字 | 做"**彼时的他 vs 此时的他**"的对比；指出他身上**变成了什么** |
| **⑤ 当下与余韵** | 150 – 250 字 | 他现在所站的位置；用意象或留白收束，不下定论 |

**结构校验口诀**：起 → 本 → 选 → 变 → 余。

## 三、势力格局解说 · 结构模板

- 对应 task_type：`faction_landscape`
- 字数区间：**1000 – 1500 字**（目标锚点 ~ 1200 字）

| 段落 | 字数区间 | 作用 |
|---|---|---|
| **① 棋局铺陈** | 100 – 200 字 | 俯视镜头，交代本阶段台面上的几方；禁用排名 |
| **② 各方画像** | 400 – 600 字 | 每方一段，用"利益—资源—目标"三元融合写法；通常 3–4 方 |
| **③ 冲突与制衡** | 200 – 300 字 | 突出"台面结盟 vs 暗流博弈"；标注 `certainty` 不同的结论口吻不同 |
| **④ 转折事件** | 150 – 250 字 | 本阶段的格局拐点（通常对应 1–2 个关键 `ev-*`） |
| **⑤ 格局走向预判** | 100 – 200 字 | 落在"**最可能被打破的那一环**"上；指向 `thread-*.status=open` |

**结构校验口诀**：盘 → 像 → 衡 → 转 → 向。

## 四、体系设定解说 · 结构模板

- 对应 task_type：`worldbuilding`
- 字数区间：**1000 – 1500 字**（目标锚点 ~ 1200 字）

| 段落 | 字数区间 | 作用 |
|---|---|---|
| **① 现象引入** | 100 – 200 字 | 典型能力展示的场景切入；不下定义 |
| **② 定义** | 100 – 200 字 | 清晰的一句话定义 + 简短背景；对应 `setting.definition` |
| **③ 条件与代价** | 300 – 450 字 | 使用这套体系的门槛与具体代价；严格区分 `explicit` / `reported` |
| **④ 限制与例外** | 200 – 300 字 | 什么时候不能用、什么情况下被破例；`inferred` 用推测口吻 |
| **⑤ 典型展示** | 150 – 250 字 | 1–2 个关键使用场景（对应 `demonstration_event_refs`） |
| **⑥ 争议或留白** | 100 – 200 字 | 体系对比、未解之谜、作者留下的伏笔；余韵式结尾 |

**结构校验口诀**：象 → 义 → 价 → 限 → 现 → 留。

## 五、感情线解析 · 结构模板

- 对应 task_type：`emotional_arc`
- 字数区间：**1000 – 1500 字**（目标锚点 ~ 1200 字）

| 段落 | 字数区间 | 作用 |
|---|---|---|
| **① 切入互动** | 100 – 200 字 | 一次意味深长的互动开篇 |
| **② 关系阶段溯源** | 500 – 700 字 | 按 `rel-*-stage-*` 展开，通常 2–4 个阶段；每阶段完成"互动→态度→心理→转折"四步闭环；贯穿一个意象 |
| **③ 转折事件** | 150 – 250 字 | 感情线的拐点事件（对应 `turning_event_refs`） |
| **④ 情感定性与边界** | 150 – 250 字 | 严格区分事实（`attitude.basis`）与推断（`assessment.category`）；保留 `uncertain` |
| **⑤ 未完余音** | 100 – 200 字 | 不给闭环答案；留一句开放式反问；对应 `thread-*.status=open` |

**结构校验口诀**：入 → 溯 → 转 → 定 → 余。

## 六、字数自检与再平衡

### 6.1 自检流程

稿件初稿完成后，LLM 必须立即执行以下 4 步自检：

1. **字数核算**：数一遍正文字数（含标点、不含脚注与元信息），记录到 `meta.word_count`。
2. **区间对照**：对照本主题的目标区间，判断是否"**偏差 ≤ 20%**"。
3. **结构对位**：对照本主题的段落表，核对每一段的字数是否在该段的推荐区间内（允许 ±30%）。
4. **节奏与金句**：按下方 §6.3 执行节奏自检。

### 6.2 再平衡规则

| 偏差情况 | 处理 |
|---|---|
| 字数 **低于下限** 但偏差 ≤ 20% | 优先在"主体/条件/变化/关系阶段"段中**补充索引里已有、但本次未展开的材料**（例如多讲一次 `ev-*`）或增补一处金句，而非注水 |
| 字数 **低于下限** 且偏差 > 20% | 检查是否 `coverage=partial`：若是，直接把稿件改为"**索引覆盖不足**"的说明稿；若否，补读索引材料后重写对应段落 |
| 字数 **高于上限** 但偏差 ≤ 20% | 优先压缩"**前情回扣/各方画像/条件代价**"中的冗余描述；保留开篇钩子、金句与结尾不动 |
| 字数 **高于上限** 且偏差 > 20% | **整段重写**；通常意味着材料筛选过宽，回到检索指南重新按"必读+可选"二分 |
| 某段字数超过该段推荐区间 30% | 优先切段：把一段切成两段，并给出小节标题（如果不打断文风） |

### 6.3 节奏与金句自检

| 检查项 | 要求 | 不达标处理 |
|---|---|---|
| **强钩子** | 前 100 字内有冲突/反差/悬念/两难抉择之一 | 整个开场段重写 |
| **节奏变化** | 主体部分**每 300–500 字至少 1 次**节奏变化（短句爆发/设问/留白/画面特写） | 在最平铺的段落中插入节奏点 |
| **金句密度** | **全文 ≥ 2 条可独立成段的金句**；位置建议见各主题 style-guide | 补写金句；若无法补写，回到结构模板检查是否遗漏关键段 |
| **结尾形态** | 章节剧情 / 感情线 → 追更钩子；人物 / 势力 / 体系 → 余韵式思考 | 结尾段重写 |
| **信息罗列型稿件识别** | 若通读后仍属无钩子/无金句/无节奏变化 → **整段重写**，而非微调 | 回到对应 style-guide 重写 |

### 6.4 "材料不足以支撑目标字数"的报告模板

若自检后发现**无法在合法索引材料内达到字数区间**，不要注水、不要凭空扩写。改为输出以下形态的稿件：

- 正文中保留**已能稳固呈现的段落**（通常是开场钩子 + 若干核心段）；
- 在正文末尾加一段"**解说员就此打住**"的交代，解释为何不继续；
- 在元信息中设置 `coverage_gaps` 并明确标注受限原因（如"该阶段 `coverage.topics[task_type]=partial`"或"turning_event_refs 均无 anchor，证据不足"）；
- 禁止把"材料不足"伪装成"意犹未尽"。

## 七、输出前的最终勾兑清单

每一次输出前，LLM 必须勾兑：

- [ ] 结构表（五段/六段）全部存在，顺序未颠倒；
- [ ] 字数在目标区间内，偏差 ≤ 20%；
- [ ] 前 100 字有强钩子；
- [ ] 主体每 300–500 字有节奏点；
- [ ] 全文 ≥ 2 条金句；
- [ ] 结尾形态与主题匹配（钩子 / 余韵）；
- [ ] 证据脚注与元信息按 `SKILL.md` 的 §输出结构 组装；
- [ ] 未触发任何写回索引的操作。
