# 第65章：成佛之问与猪圈之悟

## 开始局面

章首是一段对答：黄袍怪问孙悟空“你为什么要成佛”，叙述写明孙悟空“听见自己的心在回答”——因为佛是没有边界可约束的。黄袍怪继续追问：是否为了打碎一切界限而要成为界限；并断言孙悟空因为害怕自己的力量，所以胜不了他，还说自己五百年前根本无法阻挡孙悟空（[[claim-local-1]]、[[claim-local-2]]、[[claim-local-3]]）。这段对答的发生地点与在场第三方，本章未交代。

随后视角转开：猪八戒叼着草叶、扛着钉耙在山路上哼小曲，脚下一滑滚下山坡，直摔到山脚，摊开四肢躺着不想动。

## 关键行动

- 猪八戒的钉耙比他晚落到山脚，砸在他头上打出大包；他由此胡思乱想：若一切都是天定，天是否在他出生时就为他的死设计好了万里之外某座山上无数草的长法。
- 包不太痛后，他抬头看见山坡下的农田与阳光里的宁静村庄，流着口水走进村中；村中静悄悄，他走到一个猪圈边看圈里的猪，又低头看自己划破的衣衫和新伤旧痕，叹气说“原来我不知道什么叫幸福”（[[claim-local-7]]）。
- 少女提篮从田里回来，往自家猪圈看了一眼便大喊“老爹，我们家圈里多了一头猪”——猪八戒已躺在圈中张着嘴睡着。
- 圈中母猪与猪八戒对话，自称上辈子是天上的仙女“花花”，讲猪和人都是受规律支配的东西、超出边界又会得到另一个边界（[[claim-local-9]]）。猪八戒说自己一点儿也不想上西天，可根本没有选择，因为超不出神设下的“界限”（[[claim-local-10]]）。
- 猪八戒跳起来亮出钉耙，说“如果真是一头猪，我就把自己的鼻子吃下去”，要对方亮本相（[[claim-local-11]]）。

## 转折与新信息

- 光线大亮，猪圈在光芒下融化，猪八戒身处一座巨大殿宇，诸神高坐；强光中的声音问“猪八戒，你悟了吧”，并称唐三藏“离经叛道，自有天谴”（[[claim-local-12]]、[[claim-local-13]]）。猪八戒反问对方在怕什么，又说当初是菩萨让他们跟着唐僧上西天，如今唐僧找不着路跑了、猴子跟着小妖精飞了，历史不会写上一只猪把经文带回东土（[[claim-local-14]]）。
- 光中声音提出“如果你不再是一只猪呢”。猪八戒心绪翻涌（先咸如眼泪、再酸如五百年感伤、后腥如血），随即大骂拒绝：“现在老子就爱做一只猪”（[[claim-local-15]]）。座上转为欷歔议论，指责“一个好好的人怎么会变成这样的”“那唐僧果然是个魔障的”。
- 声音变作狂笑，殿宇消失、妖雾升起，自称“逗你玩呢，蠢猪”“你真当你见着佛祖了”，并说“金角大王说，不受点拨，就去死吧——”（[[claim-local-17]]）。
- 无数黑影穿梭，猪八戒挥耙乱挥却一个也够不到，身上不断出现伤痕，跪地自责“我又控制不住自己了”、说要回家；并说唐僧走不出迷宫、孙悟空不能杀死自己、沙僧找不着那些碎片，全是“不可能的事”（[[claim-local-19]]）。
- 他仰天一字一字大喊“我虽然是只猪！可是我不任你们宰”，吼声卷起狂风，黑影被吹散，云散开、月亮重现（[[claim-local-20]]）。

## 本章结果

猪八戒在月光下泪流满面、抖个不停、分不清方向，自语：到了西天就不能再记着“你”、永远见不到“你”，但会想着“你”、答应过“你”；随后重重栽倒在地，尘埃被风送上天空，冷月孤照（[[claim-local-21]]）。本章未交代他之后的起身、伤势与去向。章首黄袍怪与孙悟空的对答在本章亦无后续。

## 未决问题与补读入口

- 章首黄袍怪对答发生于何处、是否实境，本章未说明；需回看上一章（第64章为宝象国、黄袍怪翻看唐僧行李）与下一章衔接。
- “诸神点拨”场景由声音自己揭示为“逗你玩”，但施术者是谁、金角大王在其中的角色，本章未明示。
- 母猪“花花”自称仙女的身份仅为自身说法，且被猪八戒道破并非真猪，其真实身份待后文。
- 猪八戒口中“你”在本章未点名，只以“答应过你”的约定形式出现。
- 猪八戒提到“沙僧找不着那些碎片”，此处“碎片”的所指本章未交代，需回溯前文。
- 猪八戒提到“唐僧走不出那个迷宫”“孙悟空不能杀了他自己”，为本章对三人处境的口头概括，未有本章内的事件支撑。
