# 感情线解析 · 文风指南

> 文风名称：**心流叙事 + 情感考古**
> 适用 task_type：`emotional_arc`
> 字数区间：**1000–1500 字**（详细结构见 `structure-templates.md`）

---

## 一、文风定位

感情线解析面对的命题是：**"这两个（或几个）人之间，到底发生了什么？"**

但好的感情线解析从来不回答"**他们在一起了吗**"——它回答的是：
- **他们是从什么时候开始，不再把对方当成普通人**的？
- **他们之间最接近也最遥远的那一刻，是哪一次？**
- **他们心里真正住着的，到底是对方，还是对方的某一面？**

一句话总结：**"像考古学家一样挖证据，像心理医生一样讲心流。"**

---

## 二、核心骨架：互动 → 态度 → 心理 → 转折

感情线解析以 `rel-*-stage-*`（关系阶段快照）为骨架，一个阶段一个阶段地串联。
每一个阶段都要走完**四步闭环**：

| 步骤 | 问题 | 从索引取材 |
|---|---|---|
| **互动** | 这一阶段他们之间发生了什么关键互动？ | 该 stage 关联的 `ev-*`（对话、送礼、救助、冷战） |
| **态度** | 这些互动表现出什么态度？ | `rel-*-stage-*` 中的 `attitude.basis`（事实支撑） |
| **心理** | 他们内心真正想的是什么？ | `assessment.*` + 相关 `claim-*`；**注意 `certainty` 区分** |
| **转折** | 这一阶段的拐点在哪？ | `turning_event_refs` 中的事件 |

> **严格禁止**：把"保护"直接推理成"爱情"；把"陪伴"直接推理成"动心"；把"回眸"直接推理成"喜欢"。
> **索引怎么标，就怎么写**。

---

## 三、四条核心手法

### 手法 1：一次意味深长的互动开篇（禁用"关系综述体"）

- 开篇用**一场具体互动**切入——那种"看似无事，实则暗流"的瞬间。
- 禁用句式：
  - "XX 与 YY 的感情发展经历了以下几个阶段……"
  - "本篇讲述的是主角和女主之间的感情线……"
- 推荐开篇句式：
  - "那一夜她没敲门。她只是在门外站了一柱香，又走了。"
  - "他为她挡过一刀，没有抬头。她为他留过一盏灯，没有说话。他们之间最像夫妻的那一次，是在一场葬礼上。"

### 手法 2：事实 vs 推断 严格分离

这是感情线解析**最常翻车**的地方。
- **`attitude.basis`（事实依据）**：可以直接陈述。
  - "他连续三次在议事时都站在了她那一边——这是**原文明写**的。"
- **`assessment.category=explicit` / `inferred` / `uncertain`**：分别用不同句式。
  - `explicit`："他亲口说过：'我这一辈子，只欠她一个'——这是书中少数他亲口承认的情感宣告。"
  - `inferred`："这一阶段他对她的态度，像护犊，又不止护犊——这是从他对别人的敌意反过来推的。"
  - `uncertain`："至于那是不是爱——书里到此为止，还没给过答案。"
- **禁止**：把 `uncertain` 的推论写成"确凿的喜欢"。

### 手法 3：以意象串联而非标签贴膜

- 不要贴标签："他喜欢她 → 她也喜欢他 → 他们产生了误会 → 和好"。
- 要用**一个贯穿整段关系的小意象**：
  - 一盏灯、一个眼神、一个称呼、一次没说出口的话、一样一直没还的东西。
- 这个意象在每一个 stage 都变换一次形态，形成感情考古式的"切片对比"：
  - 第一阶段："灯是她第一次为他点的，不说话。"
  - 第二阶段："灯是他第一次为她熄的，也不说话。"
  - 第三阶段："灯还在。只是，再没有人为谁点它或熄它。"

### 手法 4：留"未完成感"收尾（禁用"HE/BE 定论"）

- 结尾**不给闭环答案**：真实的感情从来不是选择题。
- 结尾要让读者感到"**这段关系还会往哪儿走？**"
- 对应索引中 `thread-*.status=open`（感情线相关的开放线索）。
- 推荐结尾样式：
  - "所以到底是什么——是她忘不了他，还是她忘不了那年还相信能忘掉他的自己？"
  - "他们之间从来没有过那三个字。可每一次相见，都像是把那三个字，省略了一遍又一遍。"

## 四、好例 vs 坏例

### 坏例（关系综述体 + 推测当事实）

> 主角和女主的感情经历了相识、相知、相爱、分离、重逢几个阶段。两人一开始互相看不顺眼，但在一次合作中慢慢产生了感情。女主一直默默守护着主角，为他做了很多事情，可以看出她是真的爱他。主角虽然嘴上不说，但内心也是深爱女主的。他们之间的感情真挚而动人，是本书的一大看点。

**问题诊断**：
- "相识 → 相知 → 相爱"是标签式综述，没有画面。
- "她是真的爱他"、"内心也是深爱女主的"——把 `uncertain` 当 `explicit` 来写，证据级别错配。
- 没有具体互动、没有阶段切片、没有意象。
- "真挚而动人"是说教型评价，没有留给读者任何想象空间。
- 结尾封死，不留追更钩子。

### 好例（心流叙事 + 情感考古）

> 那一夜她没敲门。她只是在门外站了一柱香，又走了。
>
> 这是整部书里，他们之间最像"**什么都没发生**"的一次。可从那之后，书里再写她，笔锋总会在他身上停半拍。
>
> 他们认识的第一个阶段，书里给的说法是"**合作**"。她为他挡过一次刺客，他为她守过一次秘密——两个人都没有抬头，也都没有说谢。这个阶段，他们之间最明显的东西，是一盏灯：她每次离开他的书房，都会多留一盏灯给他。原文明写过：**"她离开时，没有熄灯。"**（第 87 章）这是她在这一阶段**唯一有迹可查**的温度。
>
> 到了第二个阶段，书里给的词换了——不再是"合作"，是"**她的事"**。他开始为了她做一些他从前绝不会做的事：在议事堂的三连公开站队、把家传的那枚令牌借给她用、乃至在一次朝会后独自去了她兄长的坟。他从不解释。但书里有一句解说员视角的旁白说得很重：**"从这一夜起，他对她的忍让，已经不像他该有的样子。"**（第 134 章）这是书里**少数**对他们关系的直接定性。
>
> 可到了第三个阶段，灯灭了。
>
> 他们之间**什么都没发生**。她不再夜访，他不再借令牌，书里甚至整整四十章没有让他们正面同场。但他们在场的每一次对话、每一场议事、每一个眼神——都比前两个阶段更像一对**在避着对方的人**。
>
> 这是不是爱？
>
> 书里从来没给过答案。连作者让一个老仆人问出口的那一次，他们两个都没有回答。
>
> 所以到底是什么——是她放不下他，还是她放不下那年还相信自己能放下他的自己？
>
> 他们之间从来没有过那三个字。可每一次相见，都像是把那三个字，省略了一遍又一遍。

**优点诊断**：
- 开篇用"没敲门"的具体互动切入，有画面、有钩子。
- 以"**灯**"为意象贯穿三个 stage：留灯 → 借令牌 → 灯灭。
- 严格区分证据：第 87 章的"没熄灯"是 explicit 原文引用；第 134 章的旁白是 explicit claim；"是不是爱"保留 uncertain。
- 结尾两句都是可截图金句，并留下未完成感。

## 五、禁用清单

| 不要写 | 原因 |
|---|---|
| "相识 → 相知 → 相爱"式阶段标签 | 关系综述体 |
| "她是真的爱他" / "内心也是深爱" | 把 uncertain 当 explicit |
| "保护她 = 爱她" / "陪伴她 = 动心" | 推理过度 |
| "他们的感情真挚而动人" | 说教型评价 |
| "最终他们在一起了" / "注定错过" | HE/BE 定论封死，没有未完成感 |
| 把 `claim.certainty=reported` 的旁人评价当成人物心理 | 证据错配 |

---

## 六、结尾收束的硬要求

- 结尾**不给闭环答案**，必须留"未完成感"。
- 必须对应索引中真实存在的 `thread-*.status=open`（感情线相关的开放线索）；若索引中该段感情线已关闭（status=closed），结尾改为"回望式"，但仍保留一句对读者的开放式反问。
- 全文至少 **2 条可截图金句**，一条放在意象对比处，一条放在结尾未完成感处。
- 严禁出现任何"证据不足却定性"的句子（例如"他爱她爱到了骨子里"而索引中并无 explicit 支撑）。
