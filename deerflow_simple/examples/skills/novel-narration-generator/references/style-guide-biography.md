# 人物传记解说 · 文风指南

> 文风名称：**人物弧光 + 命运叙事**
> 适用 task_type：`biography`
> 字数区间：**1000–1500 字**（详细结构见 `structure-templates.md`）

---

## 一、文风定位

人物传记解说的核心命题是：**"他为什么会变成现在的他？"**
不是履历、不是年表、不是功绩清单——而是**一个人在小说里的命运弧光**。

读完一篇好的人物传记解说，读者应该能感到：
- 看到了这个人**在哪一刻真正成形**；
- 理解了他身上**不可逆的代价**；
- 回味他**身上最不像自己的那一面**是如何来的。

一句话总结：**"像写一篇命运，而不是写一张简历。"**

---

## 二、三要素：选择 · 代价 · 变化

人物传记围绕三要素展开，三者缺一不可：

| 要素 | 含义 | 如何从索引取材 |
|---|---|---|
| **选择** | 他在关键节点做了什么决定 | `characters/char-*/stages/stage-*.md` 中的"关键选择" + 阶段内的 `category=choice` 事件 |
| **代价** | 这个选择让他失去了什么 | 阶段文稿中的"代价"段 + 相关 `claim-*`（`certainty=explicit`） |
| **变化** | 他因此变成了谁 | 阶段之间的差异对比（人格、能力、立场、关系） |

**写作时的呈现规则**：

- **选择要具体**：不是"他选择了反抗"，而是"他在刀锋顶住咽喉的那一夜，终究没有说出那个名字"。
- **代价要可视**：不是"他失去了很多"，而是"从此，他再也没有回过那座院子"。
- **变化要可对比**：建议至少做一次"**彼时的他 vs 此时的他**"的对比句，让弧光一眼可见。

## 三、四条核心手法

### 手法 1：代表性场景开篇（禁用"简历体"）

- **开篇用一个具体场景**：那个最能代表人物内核的时刻。
- 禁用句式：
  - "XXX，男/女，XX岁，出身……"
  - "本篇讲述的人物是……"
  - "他从小……后来……最终……"
- 推荐开篇句式：
  - "他第一次拔剑，不是为了杀谁，而是为了把自己钉在原地。"
  - "二十年后再有人提起他的名字，整个北境都会沉默三息。可那一年，他才十六岁。"

### 手法 2：第三人称全知 + 适度解说员评价

- 主叙述用**第三人称全知视角**：带读者看他做了什么、他经历了什么。
- 关键转折后**插入一到两句解说员评价**：帮读者"读懂"这件事的分量。
  - 推荐表述："从这一刻起，他身上多了一样东西——一样他余生都不会再放下的东西。"
- **禁止**整段纯议论；评价必须**紧贴场景**而非悬空抒情。

### 手法 3：原文金句的精确引用（最多 2 处）

- 必要时可引用一到两句**原文**作为"自白"或"旁证"。
- **必须通过 `anchor` 精确回读**；没有 anchor 时不要凭记忆引述。
- 格式建议：用引号 + 换行独立成段：

> "我不是不想回去。我只是……再也回不去了。"
> ——第 182 章

- 引用是用来**定钉人物灵魂**的，不是炫学。全文最多两处，不要滥用。

### 手法 4：余韵式结尾（禁用"总结式说教"）

- 禁用"总之，他是一个……的人"、"他的故事告诉我们……"。
- 推荐结尾样式：
  - **留白式**："他赢得了几乎所有人想赢得的东西。只是没有人知道，他想赢的那样东西，其实从来不在这些里面。"
  - **意象式**：用一个场景意象收尾（独自站在雪地里 / 回望空荡的书房 / 把那枚旧令牌放回匣中）。
  - **留问式**：以一个指向开篇的问题收束，让读者回味。

## 四、好例 vs 坏例

### 坏例（简历体 + 议论说教）

> 主角是本书的核心人物，男，出身贫寒。他从小就展现出不凡的修炼天赋，拜入 X 门后一步步成长为宗师级人物。他经历了很多事情，比如师门被灭、挚爱离世等，这些事情塑造了他冷酷果断的性格。他的故事告诉我们，一个人的成长往往伴随着痛苦，但正是这些痛苦让他变得强大。总之，他是一个值得尊敬的人物。

**问题诊断**：
- 开头"主角是本书的核心人物，男，出身贫寒"是典型简历体。
- "经历了很多事情，比如……"信息密度低、没有画面。
- "塑造了他冷酷果断的性格"是贴标签，不是写弧光。
- "他的故事告诉我们……"是议论文作结，不是传记。
- 全文没有一个具体场景，没有一句可以截图的句子。

### 好例（人物弧光 + 命运叙事）

> 他第一次杀人那年，才十四岁。
>
> 对方是把他从乞丐堆里拎出来、教他识字、给他第一碗热汤的那个人。那一夜之后，他再也没有在冬天怕过冷——不是因为变强，是因为他的心里从此留了一处永远烧着的火。
>
> 后来的二十年里，他学会了所有一个弟子应该学会的东西：剑法、医术、算计、沉默。他拜入了门派、立了战功、娶了妻子、埋了朋友。看上去，他活成了师父当年期望的样子。
>
> 只有他自己知道，那一碗冬天的热汤，是他余生所有选择的坐标。
>
> 直到那场雨夜。门主当着全派弟子的面要他砍下自己师弟的手——理由冠冕堂皇：维护门规。他握着剑，站了很久。久到所有人都以为他会动手。可他最后放下了剑，走出了山门，从此再未归来。
>
> 这一次，他没有伤任何人。但他比那年十四岁，杀得更彻底——他杀的，是那个曾经相信"只要活下来，就还能回去"的少年。
>
> 他赢得了一切他本来想赢的东西。只是——这些东西加在一起，也抵不过一碗冬天的热汤。

**优点诊断**：
- 开场用"他第一次杀人那年，才十四岁"切入**代表性场景**。
- 全文围绕"热汤"这个意象走弧光：少年时失去 → 中年时放下 → 最终悟出代价。
- "他比那年十四岁，杀得更彻底——他杀的，是那个曾经相信……的少年"是可截图金句。
- 结尾"抵不过一碗冬天的热汤"是余韵式收束，不说教、不下定论、让读者自己合上书。

## 五、禁用清单

| 不要写 | 原因 |
|---|---|
| "XXX，男，XX岁……" | 简历体 |
| "他的故事告诉我们……" | 议论文说教 |
| "总之，他是一个……的人" | 贴标签、无弧光 |
| 把 `revealed_at` 晚的身份当作早期阶段的既成事实 | 时序污染 |
| 把 `claim.certainty=reported` 的角色说法写成客观事实 | 证据级别错配 |
| 大量堆砌他的所有事迹 | 没有弧光的事迹堆是年表而非传记 |

---

## 六、结尾收束的硬要求

- 结尾落在"**余韵式思考**"而非"总结式说教"。
- 全文至少 **2 条可截图金句**，建议分别放在：**代价段**（他失去了什么）与**结尾段**（他是谁了）。
- 结尾与开篇形成**意象呼应**（例如开篇"热汤"→ 结尾"冬天的热汤"），让读者感到"读完了，但还在回味"。
