# 势力格局解说 · 文风指南

> 文风名称：**棋局推演 + 利益分析**
> 适用 task_type：`faction_landscape`
> 字数区间：**1000–1500 字**（详细结构见 `structure-templates.md`）

---

## 一、文风定位

势力格局解说面对的核心命题是：**"台面上这几方人，为什么是现在这个局？"**

这类解说不是"门派介绍"也不是"组织架构图"，而是：
- 让读者看到**一盘动态的棋**；
- 看懂**每一方真正想要的是什么**；
- 看明白**他们之间看得见的合作、看不见的忌惮**；
- 判断出**下一步棋，可能会往哪里走**。

一句话总结：**"像围棋复盘，而不是像组织图册。"**

---

## 二、三元框架：利益 · 资源 · 目标

每一方势力都用**"利益—资源—目标"**三元框架展开，不逐一列举成员名单：

| 维度 | 问题 | 从索引取材 |
|---|---|---|
| **利益** | 他们**不愿意失去的东西**是什么？ | `factions/fac-*/stages/stage-*.md` 中"核心利益"段 + 相关 `claim-*` |
| **资源** | 他们**用来保护利益的筹码**是什么？ | 阶段文稿中"实力/资源/关键人物"段 + 关键 `ev-*` |
| **目标** | 他们**在本阶段真正想推进什么**？ | `threads/thread-*.json` 中与该势力关联的开放线索 + `landscape/stage-*.md` |

**三元之间的张力**是整篇解说的驱动力：
- 利益与目标不一致 → 内部分裂的伏笔
- 资源不足以匹配目标 → 必须结盟或冒险
- 多方利益互相啃食 → 冲突不可避免

## 三、四条核心手法

### 手法 1：棋盘视角开篇（禁用"人物介绍体"）

- 第一段用"**整个台面**"的俯视镜头切入：这一阶段台面上有几方势力、各自占什么位置、谁盯着谁。
- 禁用句式：
  - "XX 门派是本书中最强的势力之一……"（排名型开场）
  - "XX 门派由 A、B、C 等人组成……"（组织架构表）
- 推荐开篇句式：
  - "进入这一阶段，台面上同时坐着四个人——没有一个人，是真心想谈的。"
  - "北境的雪还没化，南疆的刀已经出鞘。而真正握着线的那只手，仍在京城的屏风后面。"

### 手法 2：利益—资源—目标三合一画像

- 每一方势力的介绍段**不要分成三段写**，而是用**一段把三元融合**：
  - 坏写法："A 门派的利益是……，资源是……，目标是……"
  - 好写法："A 门派坐镇北境，手里握着整条商路的税权（**资源**），他们最怕的从来不是外敌，而是朝廷哪天把这条路收回去（**利益**）；所以在这一阶段，他们每一步都在做同一件事——把朝廷派来的人，变成自己人（**目标**）。"
- 这样写出来，一方势力一段，整个棋局自然流动起来。

### 手法 3：突出"隐藏矛盾"而非"台面结盟"

- 真正吸引人的不是"A 与 B 是盟友"，而是"**A 和 B 结盟那一刻，彼此都已经在算对方的后账**"。
- 对 `relationships/pairs/rel-*.json` 中标为"表面合作、实则博弈"的，要重点挖出来讲。
- 对结论型 Claim 的 `certainty`：
  - `explicit`：可以直接判断"A 和 B 的联盟是假的"；
  - `reported`（某角色说法）：必须写成"在 C 看来，A 和 B 的联盟是演给外人看的"；
  - `inferred`：改用"从这几次会面的细节看，这段联盟很可能并不牢固"。

### 手法 4：格局变化点收尾（而非"综述式总结"）

- 结尾不是"综上所述，本阶段势力格局呈现 X 与 Y 对立之势"。
- 结尾要落在"**下一步最可能被打破的那一环**"上——指向 `threads/thread-*.status=open` 的伏笔。
- 推荐表述："所以当你看到这一局，别只盯着台面上最大的那颗子——真正能让整盘棋翻过来的，是那颗所有人都当成死棋的子。"

## 四、好例 vs 坏例

### 坏例（组织图册式）

> 本阶段的主要势力包括 A 门派、B 王庭、C 商会和 D 教派。A 门派是最大的势力之一，由大长老领导，弟子众多，掌握北境大部分地区。B 王庭由国王统治，拥有强大的军队。C 商会主要控制商业贸易。D 教派是新兴势力，发展迅速。各方势力之间既有合作也有冲突。总体来看，本阶段格局呈现多方并立之势。

**问题诊断**：
- 每一方都在复述"名字 + 领袖 + 规模"——这是组织图册。
- "既有合作也有冲突"是废话型描述，没有具体冲突点。
- 没有利益—资源—目标的分析，读者看完不知道**他们到底在争什么**。
- 结尾"多方并立之势"是综述型总结，没有变化点、没有下一步钩子。

### 好例（棋局推演 + 利益分析）

> 这一阶段，台面上同时坐着四方。没有一方，是来谈和的。
>
> 北境的 A 门派，看上去最大。但他们真正紧的，不是版图——是手里那条压了二十年的商路。只要朝廷哪天想起要收，他们所有的刀和山头，就都是坐在火堆上的草。所以这一阶段 A 门派所有的动作，都指向同一件事：把朝廷派来的使节，一个一个变成自己人。
>
> 京城的 B 王庭，牌最硬，心最乱。年轻的国王想集权，老一辈的权臣想自保。他们对外最大的"动作"，其实只是对内最大的"分裂"的掩护。这也是为什么他们对 A 门派的商路，一直只敲打、不动手——因为真正那只敲桌子的手，自己都还没撑稳。
>
> 商会 C 看起来最没立场，恰恰是最危险的一方。他们的目标不是打赢任何人，而是让所有人都离不开他们。所以他们同时给 A 门派送粮、给 B 王庭送钱、也在悄悄资助新教 D——这三条线谁先断，他们就从哪一边撤。
>
> 至于 D 教派：他们没有兵、没有钱、没有后台。可他们有另一样东西——一群愿意为一句话去死的信徒。
>
> 四方相互盯着，看上去谁都动不了谁。
>
> 可真正能让这盘棋翻过来的，从来不是最大的那颗子，而是那颗所有人都当成死棋的子。D 的那句话，一旦说出来——谁都挡不住。

**优点诊断**：
- 开篇"没有一方是来谈和的"——棋局视角，强钩子。
- 每一方用一段完成"利益+资源+目标"的融合画像。
- 突出了隐藏矛盾（B 王庭对外敲打其实是对内掩护，C 商会的三线下注）。
- 结尾"所有人都当成死棋的子"是可截图金句，并指向 D 的 `thread.status=open` 伏笔。

## 五、禁用清单

| 不要写 | 原因 |
|---|---|
| "XX 门派由 A、B、C 等人组成" | 组织图册，不是棋局 |
| "本阶段最强的势力是……" | 没有依据的"实力排名" |
| "既有合作也有冲突" | 废话型描述 |
| "综上所述，呈现 X 与 Y 对立之势" | 综述型结尾，无变化点 |
| 把 `claim.certainty=reported` 的"某人认为"写成客观事实 | 证据级别错配 |
| 为了戏剧化编造索引中不存在的"隐藏矛盾" | 虚构伏笔 |

---

## 六、结尾收束的硬要求

- 结尾落在"**余韵式思考 / 格局变化点**"而非"综述式总结"。
- 必须指向索引中真实存在的 `threads/thread-*.status=open`。
- 全文至少 **2 条可截图金句**，一处放在"隐藏矛盾"段，一处放在结尾变化点。
