# 章节剧情解说 · 文风指南

> 文风名称：**章回体 + 悬念牵引**
> 适用 task_type：`chapter_explanation`
> 字数区间：**1500–2500 字**（详细结构见 `structure-templates.md`）

---

## 一、文风定位

章节剧情解说面向的读者场景是：**"看完一集，决定要不要看下一集"**。
所以这类解说不是复述流水账，而是用解说员的声音，**替读者重新组织一场戏剧**：钩起情绪、点亮转折、埋好下一集的引线。

一句话总结：**"像章回小说那样讲故事，像连续剧片头那样抓人。"**

---

## 二、四条核心手法

### 手法 1：冲突 / 反转开篇（禁用"综述式"）

- **开场前 100 字必须有强钩子**：冲突、反转、未解之谜、人物的两难抉择，四选一。
- 禁用"本章讲了……"、"接上文……"、"故事发展到……"等综述句式作开头。
- 推荐开篇句式：
  - "刀锋停在距离他喉咙三寸的地方。他本可以活下来——只要他说一个名字。"
  - "没有人想到，这个被所有人忽略的名字，会在三章之内，掀翻整个局面。"
  - "他跪下的那一刻，整条街的灯都灭了。"

### 手法 2：镜头感语言（一段一画面）

- **把章节当成分镜头脚本**。场景切换时另起一段，不要用"与此同时"把两场戏揉在一段里。
- **强调感官**：视觉（刀光/灯灭）、听觉（心跳声/风声）、触觉（手心的血）；但同一段落里不要堆叠超过两种感官。
- **避免写人物内心的大段心流**：心流可以有，但要像电影里的 close-up，一两句就够。

### 手法 3：短句、设问、留白（制造追更节奏）

- **每 300–500 字至少一次节奏变化**：
  - 短句爆发（三连短句、单字段）
  - 设问（"他真的还有退路吗？"）
  - 留白（"……"或空行后的孤立短句）
  - 画面特写（镜头拉近到某个细节）
- 这些节奏点要放在**转折/伏笔/爆点**的位置，不要均匀撒。

### 手法 4：追更钩子（必配 `thread-*.status=open`）

- **结尾必须留一个明确的追更钩子**，且该钩子对应索引中**真实存在**的 `thread-*.status=open` 伏笔或下一章的核心悬念。
- 禁止"虚构钩子"：不能为了勾人而编造一个书中不存在的伏笔。
- 推荐钩子样式：
  - **具体悬念**："而就在他闭上眼睛的那一刻，门外，另一双脚步正悄悄逼近。"
  - **反问收束**："可问题是——那个真正下令的人，又是谁？"
  - **断崖式短句**："风暴，才刚刚开始。"

## 三、好例 vs 坏例

### 坏例（综述体，没有钩子，没有镜头）

> 本章主要讲述了主角在山脚下与敌人展开激战，敌人实力强大，主角在战斗中陷入了劣势，但最终凭借一件师门留下的法器化险为夷。战斗结束后，主角意识到师门背后似乎还有更深的秘密，决定前往北方的某个地方继续追查线索。整个章节节奏紧凑，为后续剧情埋下了伏笔。

**问题诊断**：
- 开头是"本章主要讲述"——综述体，直接出局。
- 整段没有画面、没有短句、没有情绪起伏。
- "埋下了伏笔"是空话，没有告诉读者**到底埋下了什么**。
- 结尾不收束不勾人，像一份读后感。

### 好例（章回体 + 悬念牵引）

> 法器在他掌心烧了起来。
>
> 不是比喻——是真的烧了起来。那枚被师父压在枕下十六年的玉牌，第一次吐出金光，照亮了半边山谷，也照亮了对面那张本不该出现的脸。
>
> 他认得这张脸。可这张脸，三年前就应该死在西漠。
>
> 刀光劈下的瞬间，主角反手一招，玉牌脱手而出，撞在刀面上，发出一声让整条山脉都安静下来的闷响。敌人倒退，吐血，笑。他笑得像是看到了多年前的某个老熟人。
>
> "原来——"他说，"你还活着。"
>
> 这一句，让主角比挨那一刀还要冷。因为他听出来了：对方认得的，不是他——是他戴在身上这枚玉牌真正的主人。
>
> 师父究竟是谁？师父究竟藏了什么？师父究竟为了什么，让他活到今天？
>
> 答案没有出现。回答他的，是山谷另一头，缓缓升起的第二道金光。
>
> 风暴，才刚刚开始。

**优点诊断**：
- 开场一句"法器在他掌心烧了起来"直接抓人（强钩子）。
- 每一段都是一个画面（镜头感）。
- "他笑得像是看到了多年前的某个老熟人"是可以截图的金句。
- 三连设问（"师父究竟是谁？……"）制造节奏爆发。
- 结尾"第二道金光" + "风暴，才刚刚开始"——具体悬念 + 断崖式短句，对应 `thread-*.status=open` 的师父身份伏笔。

## 四、禁用清单

| 不要写 | 原因 |
|---|---|
| "本章讲了……" / "接上文……" | 综述体，瞬间劝退 |
| "读者可能会想……" / "笔者认为……" | 把读者推出沉浸感 |
| "总之" / "综上所述" | 这是议论文而非解说 |
| 把 `revealed_at` 晚的真相当作本章既成事实 | 剧透污染 |
| "强到爆炸" / "牛到飞起" 等网络梗 | 透支文风严肃度，影响追更氛围 |
| 完全闭环的大团圆结尾 | 没有钩子，读者没有继续追的理由 |

---

## 五、结尾收束的硬要求

- **结尾不给闭环答案**。章节剧情解说本质上是"分集解说"，必须让读者感到"事还没完"。
- 结尾钩子必须对应索引中确实存在的 `thread-*.status=open`；如果本章在索引里属于"全局收束章"（罕见），改用"回望式"收束但要留一个新开章节的指引，如"而这，不过是另一个故事的序章"。
- 全文至少要能被截出 **2 条可做封面的金句**，建议分别放在：转折处（主体）与结尾（追更钩子）。
